# v1 release notes — candidate, not published

This is the integrated **1.0.0 candidate**, not a published release, tag, remotely available install pin or approval. Plugin, dashboard, Python project and Python virtual lock member versions are 1.0.0. - Direct StudioTwin Streamable HTTP MCP for cloud tools; optional native Hermes Desktop workspace and host-scoped media backend. No local MCP wrapper or artificial credit cap.
- Library, Jobs, Concepts and Upload; image/comparison, mesh/rig/animation, panorama, material, audio and video/sequence inspection; scoped Next actions and Made from provenance.

- README install repository corrected to `realtwin/hermes-studiotwin-plugin`, while retaining plugin ID `hermes-studiotwin`; private-repository and remote Desktop/client setup clarified.
- Bundled workflow entry compacted with complete linked tool, routing, delivery and local-helper references. Captured schemas remain labeled snapshots; live discovery stays authoritative.
- Format-aware panorama exposure: PNG/JPEG sRGB backgrounds follow EV while linear HDR/EXR avoid double exposure; regression coverage compares actual WebGL pixels at single EV.
- Reproducible sequential verification runner pins the released host SHA and fixture-parity FFmpeg digest; test-only Pillow is declared explicitly.

- Explicit approval, timeout/resume, storage, removal, optional runtime and verification limits.
